A deterministic program (Python 3.13, standard library only) that renders a 1024x1024 travel poster for VELMARA — the Floating Isles, where the sea hangs in the sky. No network, no third-party packages: pure-Python PNG encoding with an embedded bitmap font.

## Run it

```sh
python3 main.py
```
